Edit Distance

What is the minimum number of insertions, deletions, and substitutions needed to transform one string into another?

DP TABLE EXECUTION READY
TABLE E[i, j] prefix X[1···i] vs Y[1···j]
Enter two strings and press RUN.
CURRENT OPERATION
READY
Build the edit-distance table by filling base cases, then each interior cell from its three neighbors.
ALIGNMENT 
—
EDIT DISTANCE O(mn) 
editdistance(X[1···m], Y[1···n])

for i ← 0 to m do
    E[i, 0] ← i
for j ← 1 to n do
    E[0, j] ← j
for i ← 1 to m do
    for j ← 1 to n do
        E[i, j] ← min{
            E[i − 1, j] + 1,
            E[i, j − 1] + 1,
            E[i − 1, j − 1] + diff(i, j)
        }
return E[m, n]
RUNNING TIME
T = O(mn)
