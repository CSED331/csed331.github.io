FIB1 vs. FIB2

FIB1 TIME Θ(1.6n)

FIB1 — RECURSION Θ(1.6ⁿ) 
FIB1(n)
  if n = 0 then
      return 0
  else if n = 1 then
      return 1
  return FIB1(n − 1) + FIB1(n − 2)
FIB1 CALL TREE
RUNNING TIME OF FIB1
T(n) = T(n − 1) + T(n − 2) + O(1)
T(n) ≈ Θ(1.6n)
FIB2 — DYNAMIC PROGRAMMING O(n) 
FIB2(n)
  if n = 0 then
      return 0
  create an array f[0, ... , n]
  f[0] = 0, f[1] = 1
  for i = 2, ... , n do
      f[i] = f[i − 1] + f[i − 2]
  return f[n]
FIB2 ARRAY BUILD Each f[i] is computed once
RUNNING TIME OF FIB2
T(n) = O(n)
OBSERVATION

Why is FIB2 so much more efficient?

FIB1 20 addition operations

The same subproblems are computed again and again.

T(n) ≈ Θ(1.6n)
VS
FIB2 6 addition operations

Each f[i] is computed once and stored for later use.

T(n) = O(n)
