Merge Sort

How does a recursive algorithm divide a problem into simpler instances and combine their solutions?

Recommended: 2 ≤ n ≤ 20

INPUT ARRAY Enter one number in each cell

MERGESORT O(n log n) 
mergesort(A[1 : n])

if n > 1 then
    m ← ⌊n / 2⌋
    mergesort(A[1 : m])
    mergesort(A[m + 1 : n])
    merge(A[1 : n], m)
